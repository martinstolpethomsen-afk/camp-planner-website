Data & GDPR

Tydelig dataopbevaring. GDPR fra start.

Camp-Planner er stadig under udvikling, men databeskyttelse skal være en del af produktet fra første dag. Denne side forklarer den nuværende opsætning og de principper, vi bygger efter.

Nuværende teknisk opsætning

Hvor data ligger i dag.

På nuværende udviklingsstadie bruger Camp-Planner et lille antal betroede services til at bygge, hoste og drive website og applikation.

GitHub

Bruges til kildekode, versionsstyring og statiske projektfiler. GitHub er ikke tiltænkt opbevaring af produktionsdata om deltagere.

Vercel

Bruges til website og frontend deployment. Vercel leverer website og applikationens frontend.

Supabase

Bruges til backend-services som database, login/authentication og applikationsdata, efterhånden som produktet udvikles.

One.com

Bruges til domæneregistrering, DNS og domænerelaterede services.

GDPR tilgang

Vores GDPR-principper.

✓

Dataminimering

Vi sigter kun efter at indsamle de persondata, der er nødvendige for at planlægge, afvikle og understøtte et event.

✓

Formålsbegrænsning

Persondata bruges til eventadministration, kommunikation, check-in, deltagerstyring, support og produktdrift.

✓

Adgangsstyring

Kunde- og eventdata bør kun være tilgængelige for autoriserede brugere baseret på rolle og organisation.

✓

Sletning og opbevaring

Eventdata bør slettes eller anonymiseres, når de ikke længere er nødvendige, med forbehold for lovkrav og driftsmæssige behov.

✓

Databehandleraftaler

Når leverandører behandler persondata på vegne af Camp-Planner eller kunder, skal relevante databehandleraftaler være på plads.

✓

Transparens

Kunder og deltagere skal kunne forstå, hvor data opbevares, og hvem der behandler dem.

Typiske datakategorier

Hvilke data Camp-Planner kan behandle.

Det færdige produkt kan behandle arrangøroplysninger, instruktøroplysninger, deltagerinformation, tilmeldingsdata, programdata, overnatningsønsker, check-in status og kommunikationshistorik. Betalingsdata bør håndteres af dedikerede betalingsudbydere og ikke gemmes direkte i Camp-Planner, medmindre det kræves til regnskab.

Ansvar

Dataansvarlig, databehandler og kundens ansvar.

For marketingwebsitet og Camp-Planners egen kommunikation er TK Virksomhedsservice / Camp-Planner ansvarlig for de persondata, der indsamles.

For kunders events kan kunden eller organisationen være dataansvarlig for deltagerdata, mens Camp-Planner kan fungere som databehandler afhængigt af den endelige kontraktuelle opsætning.

Important note

Denne side udvikles frem mod lancering.

Før kommerciel lancering bør Camp-Planner have en formel privatlivspolitik, cookiepolitik, databehandleraftale, liste over underdatabehandlere, opbevaringspolitik og sikkerhedsoverblik.
